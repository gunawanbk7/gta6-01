Solmar Bay is a complete open-world crime game in the spirit of GTA 6, built from scratch for the make.fun "Make GTA 6" competition. You are Rico Vale, a wheelman fresh out of the Solmar docks: steal cars, outrun the Solmar Bay Police, run four story missions for fixer Marla Kade, and climb from dock rat to king of the coast — all in a sun-soaked 3D coastal city with traffic, pedestrians, a beach and an ocean, rendered with three.js. Everything is original: our own city, characters, vehicles, names, story, art and sound. It plays offline in a desktop browser from static files.

## Run it

```sh
python3 -m http.server 8000 --directory game
```

Then open http://localhost:8000/ in desktop Chrome. Or serve `game/` with any static server and open `index.html`.
